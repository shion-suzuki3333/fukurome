# AdSense 配置方針（フクロメ）

収益化は低運用前提。判定 UX を壊さない位置だけに限定する。  
全体のマーケ・収益戦略は `docs/marketing-monetization.md` を参照。

## 原則

1. **判定フローを遮らない** — 形状選択・寸法入力・結果リストの途中に広告を挟まない。
2. **端末内完結を維持** — 広告タグを足しても、寸法データを自前サーバーへ送らない。
3. **YMYL を避ける** — 医療・法律・投資の助言に見せない。家庭の買い物補助であることを明示する。
4. **モバイルで押しにくい** — CTA「合う袋を判定する」の直上・直下に広告を置かない。

## 推奨スロット（実装前の設計）

| 場所 | 形式 | メモ |
|------|------|------|
| 結果リストの下 | レスポンシブ | 判定後の離脱ポイント。コピー CTA の後 |
| 測り方ガイド末尾 | レスポンシブ | 記事読了後 |
| FAQ とフッターの間 | アンカー以外 | 初回ビューポート外 |

ヒーロー・ステップインジケータ・入力欄まわりには置かない。

## 実装メモ

- `next/script` で読み込み、本番ドメイン確定後にパブリッシャー ID を環境変数化。
- CSP に Google 広告ドメインを追加するときは最小許可に留める。
- クリック誘導文（「広告をクリックして」等）は禁止。

## まだやらないこと

- 自動再生動画広告
- インタースティシャル（判定ボタン直後）
- 結果を広告リンクに差し替えるアフィリエイト混同
