# フクロメ — 具体的プロモーション手順

方針の背景は `marketing-monetization.md`。ここは**そのまま実行できる手順と文面**。

前提: 本番URLを `https://YOUR.DOMAIN` に置き換える。断定・ステマ・ネガキャン禁止。

---

## Phase 0 — 公開前（必須）

1. ドメイン取得・HTTPS デプロイ
2. `.env` に `NEXT_PUBLIC_SITE_URL=https://YOUR.DOMAIN`
3. `npm run build && npm test`
4. [Google Search Console](https://search.google.com/search-console) でプロパティ追加 → sitemap `https://YOUR.DOMAIN/sitemap.xml` 送信
5. プライバシー / 免責 / 記事2本がインデックス対象になっていることを目視

---

## Phase 1 — 検索（最初の2週間）

### やること

| # | 作業 | 具体 |
|---|------|------|
| 1 | タイトル確認 | 記事H1にクエリ語が入っているか（合わない / 測り方 / 45L） |
| 2 | 内部リンク | 各記事末尾の「判定する」が `/#checker` を指す |
| 3 | 新規1本 | 「丸型ゴミ箱 ゴミ袋」意図で `/articles/marugata-gomi-bukuro` を追加（余力があれば） |
| 4 | GSC監視 | 表示回数が出たら、CTRの低いクエリだけタイトル微調整 |

### やらない

毎日の記事量産、他サイトコピペ、キーワード羅列メタ。

## Phase 2 — SNS（週1〜2で足りる）

### X（旧Twitter）投稿テンプレ

**投稿A（失敗談 → ツール）**

```
ゴミ袋、L数だけで選んでゴミ箱に合わなかったことある人いる？

同じ45Lでも口の幅が違うことがあって、
測るなら「口の内側」と「高さ」の2つだけでだいたい分かる。

寸法入れるだけの目安ツール作った（端末内で計算・送信なし）
https://YOUR.DOMAIN/#presets

※自治体指定袋やメーカー実寸があればそちら優先
```

**投稿B（図解・測り方）**

```
ゴミ箱に袋を合わせる測り方（30秒）

1. 縁の「内側」を測る（外寸じゃない）
2. 角型→長辺と短辺 / 丸型→直径
3. 底から縁までの高さ

手順ページ: https://YOUR.DOMAIN/guide
そのまま判定: https://YOUR.DOMAIN/#checker
```

**投稿C（共有リンク実演）**

```
キッチン中くらいのゴミ箱（例: 32×28×50cm）だと
目安はだいたい45L帯、という結果になった。

同じ条件で試す↓
https://YOUR.DOMAIN/?shape=rect&w=32&d=28&h=50#results

※一般的な袋寸法の概算です
```

### note（月0〜1）

タイトル例:「一人暮らしのゴミ袋、L表記だけで選ぶと失敗しやすい理由」  
構成: 失敗談 → 口まわりの話 → 測り方3手 → フクロメリンク → 免責一文。  
末尾に「プロモーションを含みません / 自作ツール」と明記。

### 知恵袋・教えてgoo（偶発）

既存の「ゴミ袋 サイズ わからない」系質問に、**測り方手順だけ**で回答。  
補足として「自分が作った目安ツール」と断りを入れてリンク。宣伝だけの回答は避ける。

## Phase 3 — AdSense（流入が付いてから）

1. コンテンツ・ポリシーページが揃っていることを確認
2. 申請
3. 通ったら **結果リストの下に1枠だけ**（`adsense.md`）
4. クリック誘導文は書かない

アフィリエイトを足すなら記事末尾のみ +「PR・広告」表記。結果カードには付けない。

---

## Phase 4 — 伸びたときだけ

| シグナル | 次の一手 |
|----------|----------|
| 「丸型」クエリが増えた | 丸型専用記事を1本 |
| 共有リンク経由が多い | Xでプリセット実演を月1 |
| 直帰が高い | ヒーローCTAをプリセットに寄せる（実装済み寄り） |

## 炎上・ポリシー事故の回避（再掲）

- 「絶対合う」禁止
- 特定メーカー叩き禁止
- 結果＝商品推薦に見せない
- 自治体ルールの断定禁止
- 個人寸法の収集を匂わせない
