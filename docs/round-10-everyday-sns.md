## SNS / note で見えたクラスタ

| クラスタ | 声の例 | JPツール状況 |
|---|---|---|
| あと何日・期限 | note「カレンダーで数えるのが面倒」 | 日数計算が飽和 |
| 割り勘・幹事精算 | note「誰が誰にいくら」 | シャリカン / Xenuto 等で飽和 |
| ご祝儀・香典・お返し | note「いくら包む／返す」 | 冠婚葬祭なび・手軽屋等で飽和 |
| フリマ送料・荷物サイズ | 「毎回調べ直す」 | サクポチ / mnavi 等で飽和 |
| コンビニ原寸印刷失敗 | 型紙・うちわ・同人で縮小トラブル多発 | 記事多い。ぴたプリ等あり。店別適性はまだ薄い |
| ゴミ袋の地味ストレス | インスタ297万再生「交換が面倒」 | 早見表はある。口径→適合の対話型は薄い |

## 飽和で見送り（日常でも採用しない）

割り勘、ご祝儀/香典/お年玉/お返し単体、日数カウント、フリマ送料、機内持ち込み、服サイズ換算、洗濯表示、チップ計算、賞味期限トラッカー、証明写真メーカー、SNS画像リサイズ。

## 採用候補（日常 × 収益 × 低運用）

### E10-1 ゴミ箱×ゴミ袋 適合チェッカー（推奨）
- **ターゲット**: 一人暮らし〜家庭。引越し・買い替え時＋日常の買い足し
- **SNS根拠**: ゴミ袋交換の地味ストレスがバイラル（ORICON報道のインスタ297万再生級）。ハウジー等でも「合わない」解説需要
- **コア**: ゴミ箱の口径周長・深さ（or 型式）→ 合う袋L数・寸法・余白目安を即判定。自治体指定袋は「寸法だけ」モードで対応
- **採用理由**: 母数大きい／非YMYL／幾何ルールで低運用／ツールファームの「早見表」より対話型に寄せられる
- **批判**: メーカー寸法のバラつき → 目安＋測り方ガイド必須。ゴミ分別（自治体ごと）には手を出さない（鮮度戦争）

### E10-2 コンビニ原寸プリント適性チェッカー
- **ターゲット**: 型紙・うちわ文字・同人・証明写真をコンビニで出す人
- **SNS根拠**: 「縮小された」「用紙に合わせるで失敗」系のブログ・手芸サイトが継続
- **コア**: 画像/PDFを端末内解析 → px・dpi・用紙 → セブン/L/FM別のOK・注意・NGと店頭設定チェックリスト
- **採用理由**: 痛みが具体的でリピート検索あり。ガイド記事と相性が良い
- **批判**: ぴたプリ等と被る面あり。コピー機仕様変更でルール更新が必要（出典URL＋更新日で抑える）

### E10-3 幹事の会費逆算シミュレータ（二次会・同窓会・歓送迎会）
- **ターゲット**: たまに幹事になる社会人
- **SNS根拠**: 幹事負担・会費設定・ドタキャンの不安がnote/同窓会ガイドに多い
- **コア**: 人数見込み・料理単価・雑費・幹事免除・ドタキャン予備 → 1人会費と赤字ラインを逆算（当日割り勘ではない）
- **採用理由**: 「精算ツール」飽和の横に、企画段階の逆算ニッチが残る
- **批判**: Xenutoのキリよく逆算やExcelテンプレと競合。差別化は「イベント種別プリセット＋赤字シミュレーション＋共有URL」に寄せる必要
